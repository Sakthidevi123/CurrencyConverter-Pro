# Currency Converter Pro

A simple desktop currency converter built with Java Swing.

## What is this?

Currency Converter Pro helps you convert amounts between different currencies using live exchange rates.

It also supports offline use, favorites, conversion history, CSV export, themes, settings, and a mini calculator.

## Why did I build this?

I built this project to practice Java, Swing UI development, API integration, file handling, and creating a complete desktop application with a custom user interface.

## How to use

1. Download the latest Windows ZIP from **Releases**.
2. Extract the ZIP file.
3. Open `CurrencyConverterPro.exe`.
4. Enter an amount.
5. Select the **From** and **To** currencies.
6. Click **Convert**.

That's it.

## Built With

- Java
- Java Swing
- Graphics2D
- REST API
- SwingWorker
